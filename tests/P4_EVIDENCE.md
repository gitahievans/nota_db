  explicit conflicting/unknown context, separate concert-pitch key estimates,
  XML accidental observations, normalized numeric tempo with source references,
  text suggestions/default separation and full cross-part sounding sonorities.

  unisons, spelling, transposition and tentative root/bass/inversion. Unsupported
  states and membership bounds never return an apparently complete partial list.

  `tempo` is a renderable string with structure in `tempo_analysis`; `key` labels
  its estimate; `chords` retains string pitch/numeric offset and now covers the
  combined score without the ten-result cap. No unavailable source index is
  silently replaced with an apparently mapped interpretation.

  and use the explicitly contributing event IDs. P3 extraction, schema, revision
  rules, locations, source ordinals and traversal contracts are unchanged. This
  also avoids rescanning every source event for every new combined sonority.
- `files/views.py`: existing optional summary prompt distinguishes signatures
  from estimates, sonorities from progressions, and alterations from printed
  accidental signs. No additional AI/model call or provider was introduced.
- `files/reliability/tonal.py`, `files/tests.py`, `files/reliability/baseline.py`:
  all three resolved P4 probes moved into passing discovery; 21 additional checks

  retaining both distinct source IDs/staff contexts. No identity assertion was
